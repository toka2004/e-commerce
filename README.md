# E-Commerce Web Application

A full-stack e-commerce web platform built with PHP and MySQL.

## Features
- User registration and authentication
- Product catalog and browsing
- Shopping cart management
- Admin dashboard to add/edit/manage products
- Integrated MySQL database

## Built With
- PHP
- MySQL
- HTML / CSS / JavaScript

## Setup
1. Clone the repository.
2. Import `store_db.sql` into your local MySQL server (e.g., via phpMyAdmin).
3. Update `config.php` with your local database credentials.
4. Run the project on a local server (XAMPP / WampServer).
